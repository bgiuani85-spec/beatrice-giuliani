# Portfolio Web Personale

Progetto realizzato per il corso di sviluppo web. Il sito è un portfolio personale multilivello sviluppato con un'estetica editoriale pulita e ad alto contrasto.

## 🚀 Tecnologie Utilizzate
* **HTML5**: Struttura semantica avanzata per tutte le pagine (`index.html`, `cv.html`, `contatti.html`).
* **CSS3 / SCSS**: Preprocessore Sass per la gestione modulare degli stili, palette colori e temi (Light/Dark).
* **Bootstrap 5**: Grid system responsive e componenti dell'interfaccia.

## 📁 Struttura del Progetto
* `/assets/img/` - Immagini, icone e favicon del sito.
* `/css/` - Foglio di stile compilato finale (`style.css`).
* `/scss/` - File di stile sorgente con variabili e nesting (`style.scss`).
* `index.html` - Homepage con presentazione dei servizi.
* `cv.html` - Pagina Curriculum Vitae editoriale.
* `contatti.html` - Form di contatto e FAQ in modalità Dark Theme.

## 📌 Note di Sviluppo
Il file `scss/style.scss` funge da **single source of truth** per la gestione di tutti gli stili del progetto.
